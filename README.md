## 安装说明

1. 下载对应设备的 APK 文件。
2. 在设备上允许「安装未知来源应用」。
3. 点击 APK 安装。TV / 车机设备可先下载到手机或电脑，再通过 U 盘、局域网共享等方式传到设备上安装。
