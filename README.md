## 安装说明

1. 下载对应设备的 APK 文件。
2. 在设备上允许「安装未知来源应用」。
3. 点击 APK 安装。TV / 车机设备可先下载到手机或电脑，再通过 U 盘、局域网共享等方式传到设备上安装。

## 手机端显示「加载失败」？

1. 先确认版本：设置 → 应用 → WarmCore，版本号必须是 **1.0.1**；不是就说明装的是旧包，请用上方直链重新下载安装。
2. 版本正确仍失败：切换 WiFi / 蜂窝网络后重试；仍不行请截图反馈错误文案。
